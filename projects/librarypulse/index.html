Who could use this?

Public-library staff

Review changes in borrowing and category usage. Combine these insights with holds, copy counts, and librarian judgment before acquisition decisions.

Academic librarians

Explore demand around a semester. A pilot would need course calendars, reliable catalog metadata, and approved institutional data.

Collection managers

Investigate popular and overlooked subjects. Branch transfers and demand forecasts are future extensions, not implemented features of this demo.

Behind the interface

The Python repository contains CSV/synthetic ingestion, temporal and behavioral features, and a hybrid engine using ALS, SVD, TF-IDF, and optional BERT components. FastAPI exposes recommendation, similar-book, explanation, and health endpoints; Streamlit provides the original application interface.

This static companion runs on GitHub Pages alongside the portfolio. Hosting the Python application is a separate step. Benchmark results are not yet published in the repository, and some monitoring paths use simulated values.
